# NOVA/FORM

NOVA/FORM is an independent front-end design concept exploring editorial layouts, responsive interaction, motion, data-inspired interface details, and an interactive Three.js hero.

This repository is a standalone portfolio/demo project. The names, project studies, metrics, and brand presented in the interface are fictional and are included only to demonstrate the design system and interaction work.

## Live demo

GitHub Pages target: `https://carinotj19.github.io/nova-form-studio/`

Deployment is handled by the included GitHub Pages workflow.

## Run locally

```powershell
npm install
npm run dev
```

Open the URL printed by Vite (normally `http://localhost:5173/`).

## Validate

```powershell
npm run check
npm run build
```

## Stack

- Vite
- Vanilla JavaScript
- CSS
- Three.js
- Native browser APIs

## Notes

No production client credentials, analytics IDs, private contact details, or third-party business branding are required by the demo.
